# Python practice snippets

Short examples of Python basics, including loops, string operations, `map`, exception handling, and classes. Open a file to read the example, or run a specific script with Python 3. The `eval` exercise is for studying the built-in with trusted expressions.

## Examples by concept

- Iteration: [for loops](for.py), [map](map%28%20%7Bdtype%7D%20%2C%20...%29.py)
- Strings: [replace](replace%28%29.py), [split and strip](split%28%29_vs._strip%28%29.py)
- Python structure: [exceptions](try_except.py), [classes](OOP.py), [expression evaluation](eval%28%29.py)

From the repository root, run a sample with `python for.py`.
